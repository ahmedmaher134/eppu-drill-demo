# EPPU Drill Manager (demo)

A free, self-contained demo of an emergency-drill lifecycle app for a hospital
emergency-preparedness unit. It is a prototype to agree the solution before it is rebuilt on SAP BTP.

**Steps 1 and 2 (this version):** annual drill schedule from frequency rules, proponent date picking with
checks, OEMC approval, copy for MOH / MSMD, change control with the original date kept, drill scripts
with a story vs event-list check and OEMC review, and the observer drill-day screen (checklist,
participants by badge, findings, result).

- Open `index.html` in any browser. No sign-in, no install.
- All data is fictional sample data. Changes are saved only in your browser; **Reset** restores the sample.
- "View as" in the header switches between EPPU admin, proponent, OEMC reviewer and observer.
